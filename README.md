# Event Management Platform

Java-based event management application developed to organize registrations, participant management, and operational workflows for academic and corporate environments.

The project was designed with focus on maintainability, business process organization, and administrative control.

---

## Overview

GestaoEventos is an event management system created to centralize operational event workflows, participant registrations, and organizational processes in a single platform.

The application simulates real-world scenarios commonly found in academic institutions, internal corporate events, and training management environments.

---

## Features

- Event registration and management
- Participant registration
- Administrative control panel
- Event scheduling
- Operational workflow organization
- Data persistence
- CRUD operations
- User interaction management
